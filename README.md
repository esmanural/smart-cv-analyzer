# smart-cv-analyzer

A simple Python tool designed to analyze the match rate between a resume (CV) and a job description by comparing keywords.

## Features
* Extracts and compares keywords from CVs and job postings.
* Calculates an estimated match percentage.
* Lightweight and built with pure Python.

## How to Run
1. Make sure you have Python installed.
2. Run the script in your terminal:
   ```bash
   python main.py
